# First Frost · The Scoreboard

The public prediction ledger of [First Frost](https://firstfrost.news), a scored weekly watch on the agent economy.

Every question on the panel was frozen before the fact — criterion, settlement date, and our prior probability. When settlement day comes, we grade ourselves in public: Brier scores, a flat 0.25 penalty for any voided question, and ambiguities resolving against our own thesis.

Changes to the panel happen only by commit. **The git history is the point** — it is the timestamp proof that our bets were placed before the outcomes.

- `index.html` — the scoreboard, human-readable
- `data/indicators.json` — the same ledger, machine-readable
